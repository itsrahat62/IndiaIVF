# IndiaIVF — ভারতে আইভিএফ সিদ্ধান্ত-সাইট

কলকাতা বাদে ভারতের IVF সেন্টার নিয়ে একটি ব্যক্তিগত গবেষণা-রিপোর্ট (বাংলা)।
একটি ওভারি + বারবার ফিরে আসা এন্ডোমেট্রিওমা — এই কেসকে সামনে রেখে সাজানো।

**খোলার নিয়ম:** `index.html` ডাউনলোড করে ব্রাউজারে খুলুন। ফাইলটি সম্পূর্ণ স্বয়ংসম্পূর্ণ
(ফন্ট, CSS, ডেটা সব ভেতরে) — ইন্টারনেট ছাড়াই চলে, মোবাইলেও।

## ভেতরে কী আছে
- টপ ৫ সেন্টার + মোট ১৪টির পূর্ণ প্রোফাইল (ডাক্তার, প্রকাশিত জন্মহার, খরচ, যোগাযোগ)
- ইমেইল / WhatsApp / ফোন — প্রতিটি সেন্টারের
- আশপাশের হোটেল (দূরত্ব, ফোন, ভাড়া)
- ফ্লাইট ভাড়া (Google Flights, ১৮ আগস্ট ২০২৬) ও কোন মাসে সস্তা
- ভিসা (MED / MED-X), অ্যাপয়েন্টমেন্টের ধাপ ও ইমেইল টেমপ্লেট
- দুজনের (এবং মা সঙ্গে গেলে) পূর্ণ বাজেট — সব টাকায়, রেট বদলানো যায়
- ভারতীয় ART আইন, বাংলাদেশিদের অভিজ্ঞতা, সূত্র-তালিকা

> চিকিৎসা-পরামর্শ নয় — ডাক্তারের সঙ্গে সিদ্ধান্ত নেওয়ার প্রস্তুতি।
> সব তথ্য ১৮ আগস্ট ২০২৬-এর; যাওয়ার আগে সেন্টার/ব্যাংক/এয়ারলাইনে মিলিয়ে নিন।
