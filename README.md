# IndiaIVF — ভারতে আইভিএফ: সিদ্ধান্ত-সাইট (বাংলা)

বাংলাদেশ থেকে ভারতে IVF করাতে যাওয়া দম্পতিদের জন্য একটি স্বয়ংসম্পূর্ণ বাংলা গাইড।
**লাইভ:** https://itsrahat62.github.io/IndiaIVF/

`index.html` একটি একক ফাইল — ফন্ট, CSS, ডেটা সব ভেতরে। ডাউনলোড করে ইন্টারনেট ছাড়াই
ব্রাউজারে খোলা যায়, মোবাইলেও চলে।

## ভেতরে কী আছে

- **টপ ৫ সেন্টার** + মোট ১৪টির পূর্ণ প্রোফাইল — ডাক্তার, প্রকাশিত জন্মহার, খরচ, যোগাযোগ
- **Google রিভিউ যাচাই** — কোনটার রিভিউ সাজানো, আসল রোগীরা কী অভিযোগ করেন
- **সাফল্য যাচাই** — কেন "৭০–৮৫% সাকসেস" দাবি অর্থহীন, কোন ৪টি সেন্টারের peer-reviewed ডেটা আছে
- **যোগাযোগ** — প্রতিটি সেন্টারের ইমেইল, WhatsApp, ফোন, অ্যাপয়েন্টমেন্ট পোর্টাল
- **ফ্লাইট প্ল্যানার** — ৩টি ক্লিকে: শহর, কবে, কত দিন → ভাড়া, ঈদ/উৎসবের সতর্কতা ও সরাসরি সার্চ-লিংক
- **ব্যাগেজ** — কোন এয়ারলাইনে কত কেজি, অতিরিক্ত ব্যাগের দাম, ইনজেকশন বহনের নিয়ম
- **ভিসা A–Z** — কোন পোর্টালে আবেদন, হাসপাতালের ইনভাইটেশন লেটার, IVAC-এর ৫টার স্লট-যুদ্ধ, ফি, কাগজ, এবং "সমস্যা → কারণ → সমাধান" টেবিল
- **বাসা ও রান্না** — কিচেনসহ ফ্ল্যাট কীভাবে খুঁজবেন, শহরভিত্তিক এলাকা, দালাল এড়ানোর উপায়
- **সিম ও অ্যাপ** — কোন সিম কত টাকায়, কোন অ্যাপ বিদেশি পাসপোর্টে চলে
- **আঞ্চলিক আদব-কায়দা** — কোন রাজ্যে কী নিয়ম, ভাষা, জরিমানা হয় যেসব কাজে
- **চিকিৎসাকালীন প্রস্তুতি** — দিন-ভিত্তিক সূচি, ইনজেকশন সংরক্ষণ, OHSS-এর বিপদ-চিহ্ন
- **ব্যাংকিং** — কত ডলার নেওয়া যায়, কীভাবে অনুমোদন, কোনটা বেআইনি
- **বিপদে পড়লে** — বাংলাদেশ হাইকমিশন (কোন শহর কার অধীনে), পুলিশ, হেল্পলাইন, পাসপোর্ট হারালে
- **পূর্ণ বাজেট** — দুজনের (ও অ্যাটেনডেন্টসহ) হিসাব, সব টাকায়, রেট বদলানো যায়
- ভারতীয় ART আইন, বাংলাদেশিদের অভিজ্ঞতা, সূত্র-তালিকা
